# GetSkinsInfo

-> Saves an ordered array with Skin name[ru, en, ua], skin id, skin rarity and skin screenshot link <-

1. Build project as jar
2. Open CMD

-> Convert \\csgo\\resource\\csgo_russian.txt and \\csgo\\resource\\csgo_ukrainian.txt files to UTF-8 format <-

3. Run project with "java -jar \getSkinsInfo.jar"
4. Wait for result (Array is saved as weapons.json file)

-> Skips vanila and non-skinned items and adds them into errors.log file <-
